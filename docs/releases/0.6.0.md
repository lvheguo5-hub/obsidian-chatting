Chatting with AI 0.6.0 adds richer vault queries, Canvas tools, web-page reading, message actions and image tools.

- Find notes by tags and properties; inspect incoming, outgoing and unlinked mentions.
- Read, edit, search and preview Canvas files; show vault images to the model. Oversized source images show file cards in Canvas previews to bound mobile decoding memory.
- Read HTTP(S) web pages as text, including user-requested addresses reachable on the local network.
- Configure Enter-to-send, enable a diagnostic log, and keep the screen awake during answers where supported.
- Edit earlier messages, copy answers and regenerate while keeping UI and provider history aligned. Editing does not undo vault changes.
- Save attached image data once in chat format v2. Older chats migrate on load; downgrading to an older plugin preserves the newer archive but starts an empty chat.

Thanks to **Thomas Schierl (@thomas0schierl)** for PRs #24–#30. Original commits and authorship are preserved.

Validation: 316 automated tests, TypeScript and Svelte checks, production build, native Obsidian integration, and real ChatGPT desktop/iPhone flows. See docs/phase2-review.md for evidence and limits. Minimum Obsidian version remains 1.11.4.
